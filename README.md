# Pitone

Progetto personale non ufficiale per imparare Python seguendo il programma di
[CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) e ripassare la matematica delle superiori.
Non è affiliato a CS50 né a Harvard University.

- App web: `index.html` (pubblicata con GitHub Pages)
- App Android: `Pitone.apk` (versione 3.6)
